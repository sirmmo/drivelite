Any folder, as a gallery

drivelite turns a mounted directory into a Google-Drive-style web UI: browse folders, preview photos and video, download files or whole folders — behind a minimal login.

Quick start

One command. Mount the folder read-only and set a password.

docker run -d --name drivelite -p 8080:8080 \
  -v /path/to/your/folder:/data:ro \
  -e DRIVELITE_PASSWORD='pick-something-good' \
  ghcr.io/sirmmo/drivelite:latest

Open http://localhost:8080 and sign in as admin.

docker compose

services:
  drivelite:
    image: ghcr.io/sirmmo/drivelite:latest
    ports: ["8080:8080"]
    volumes:
      - ./share:/data:ro      # your folder, read-only
      - thumbs:/cache         # thumbnail cache, keep it outside the folder
    environment:
      DRIVELITE_PASSWORD: "change-me"
      DRIVELITE_TITLE: "Shared Files"
      DRIVELITE_SESSION_KEY: "a-long-random-string"
    restart: unless-stopped

volumes:
  thumbs:

From source

git clone https://github.com/sirmmo/drivelite.git && cd drivelite
go build -o drivelite .

DRIVELITE_ROOT=./share \
DRIVELITE_CACHE_DIR=./cache \
DRIVELITE_PASSWORD=dev \
./drivelite

Needs Go 1.23+. There are no third-party modules to fetch.

What you get

A viewer, not a file manager — and that limit is the point.

Grid and list

Breadcrumbs, sorting by name, date or size, folders first. Your view choice is remembered.

Thumbnails

Generated on demand, cached to disk, and EXIF-orientation aware so camera photos are never sideways.

Media viewer

Full-screen lightbox with arrow-key navigation. Video and audio play inline with seek support.

Downloads

Single files, or an entire folder as a streaming ZIP. Already-compressed formats are stored, not re-deflated.

Search

Recursive filename search from wherever you are. Press / to jump to the box.

Read-only

Never writes to the served folder. Thumbnails live in a separate cache, and startup fails if you point it inside.

Configuration

Everything is an environment variable. Only the password is required.

DRIVELITE_CACHE_DIR/cacheThumbnail cache. Must be outside ROOT.
DRIVELITE_ADDR:8080Listen address.

DRIVELITE_PASSWORD—Password for the single account.
DRIVELITE_USERadminUsername paired with the password.
DRIVELITE_USERS—Several accounts: alice:secret,bob:hunter2.

DRIVELITE_SESSION_KEYrandomHMAC key. Set it to keep sessions across restarts.
DRIVELITE_SESSION_HOURS168Session lifetime.
DRIVELITE_SECURE_COOKIEfalseSet true when serving over HTTPS.
DRIVELITE_THUMB_PX400Longest edge of a thumbnail.

It will not start without credentials. Unless you explicitly set DRIVELITE_ALLOW_ANONYMOUS=true, drivelite refuses to boot with no password — so an unauthenticated deployment is always a deliberate choice rather than an oversight.

Behind a reverse proxy

drivelite speaks plain HTTP. Put TLS in front of it.

Over plain HTTP, credentials travel in the clear. The password and session cookie are readable by anything on the path. Terminate HTTPS at a proxy and set DRIVELITE_SECURE_COOKIE=true before exposing it beyond a trusted network.
Traefik (docker labels) 
services:
  drivelite:
    image: ghcr.io/sirmmo/drivelite:latest
    volumes:
      - ./share:/data:ro
    environment:
      DRIVELITE_PASSWORD: "change-me"
      DRIVELITE_SECURE_COOKIE: "true"
    labels:
      - traefik.enable=true
      - traefik.http.routers.drivelite.rule=Host(`files.example.com`)
      - traefik.http.routers.drivelite.entrypoints=websecure
      - traefik.http.routers.drivelite.tls.certresolver=letsencrypt
      - traefik.http.services.drivelite.loadbalancer.server.port=8080

Note there is no ports: entry — the container is reachable only through Traefik, not directly.

Caddy 
files.example.com {
    reverse_proxy drivelite:8080
}
nginx 
server {
    listen 443 ssl http2;
    server_name files.example.com;

    location / {
        proxy_pass         http://127.0.0.1:8080;
        proxy_set_header   Host $host;
        proxy_set_header   X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header   X-Forwarded-Proto $scheme;

        # Large media and ZIP streams
        proxy_buffering    off;
        client_max_body_size 0;
    }
}

Security model

A read-only viewer with one shared password. Here is exactly what that means.

What it defends against

  • Path escape. Request paths are cleaned lexically, then the resolved path is checked again after symlink resolution — so a link inside the tree cannot point outside it. Symlinks leaving the root are skipped in listings entirely.
  • Session forgery. Cookies are HMAC-signed, carry an expiry, and are invalidated the moment a user is removed from the configuration.
  • Content injection. Only recognised media is served inline. HTML, SVG and unknown types are forced to download so they cannot execute in the app's origin. A strict CSP applies and the UI has no inline script.
  • Timing and guessing. Password comparison is constant-time — unknown usernames do the same work — and logins are rate limited per IP.

What it deliberately does not do

  • No per-folder permissions. Anyone with the password sees the whole tree.
  • No TLS. Use a reverse proxy.
  • No secret store. Passwords come from the environment.
  • No write path at all. No upload, rename or delete — by design.
Found a vulnerability? Please report it privately via a security advisory rather than a public issue.

Format support

Honest about what works, because a broken preview is worse than none.

FormatThumbnailInline previewDownload
JPEG, PNG, GIFYesYesYes
WebP, HEIC, AVIF, RAWIcon onlyIf the browser supports itYes
MP4, WebM, OGVIcon onlyPlays, with seekingYes

Thumbnails cover what the Go standard library can decode. Supporting HEIC or RAW previews would mean adding a dependency or cgo; keeping the binary self-contained was judged the better trade. AVCHD camcorder files play in no browser at all, so drivelite detects them and offers a download button rather than a player that would sit there dead.

Endpoints

Everything works with curl using HTTP Basic auth.

PathPurpose
/, /browse?p=Folder listing
/search?q=&p=Recursive filename search
/raw?p=File contents, inline, with Range support
/dl?p=File contents as a download
/thumb?p=&w=Cached thumbnail
/zip?p=Folder as a streaming ZIP
/api/list?p=Directory listing as JSON
/healthzLiveness probe
 
# list a folder as JSON
curl -u admin:pass 'http://localhost:8080/api/list?p=holiday' | jq

# download one file
curl -u admin:pass -O -J 'http://localhost:8080/dl?p=holiday%2Fbeach.jpg'

# grab an entire folder
curl -u admin:pass -o holiday.zip 'http://localhost:8080/zip?p=holiday'
Why ?p= instead of a path? Filenames containing #, % or spaces silently break path-based URLs — # is a fragment delimiter, so everything after it never reaches the server. Carrying the path in a query parameter avoids the whole class of problem. Spaces encode as %20 so links stay copy-pasteable.

Questions

Can I upload or delete files through it?

No, and that is deliberate. drivelite has no write path at all, which is what lets you mount the data volume :ro and make a simple promise: your files are never touched. If you need a full file manager, drivelite is the wrong tool.

How much does it cost to run?

The image is about 20 MB and idles at a few megabytes of RSS. Thumbnail generation is the only real work: roughly 0.5–1.5 s for a large camera JPEG the first time, then served from cache. A 50-photo folder warms in under half a minute with the default four workers, once, forever.

Where do thumbnails go?

Into DRIVELITE_CACHE_DIR, never into the folder you are sharing — startup fails if you point the cache inside the served root. Cache entries are keyed by path, modification time, size and width, so editing a file naturally invalidates its thumbnail. The directory is safe to delete at any time.

Can I run it without a password?

Yes, with DRIVELITE_ALLOW_ANONYMOUS=true. It has to be explicit, and the service logs a warning on every start. Reasonable on a trusted LAN; think carefully anywhere else.

Does it work on a Raspberry Pi?

Yes — images are published for linux/amd64 and linux/arm64, and release binaries also cover 32-bit ARM. Thumbnail generation is CPU-bound, so consider lowering DRIVELITE_THUMB_JOBS on a small board.
